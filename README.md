# Barsan Banerjee – Personal Portfolio

A modern, high-performance personal portfolio website built with HTML5, Vanilla CSS, and JavaScript.

🌐 **Live URL:** [https://barsan-collab.github.io/portfolio/](https://barsan-collab.github.io/portfolio/)

---

## 🚀 Features

- **Cyberpunk / Glassmorphic Aesthetic:** Deep dark theme with glowing emerald and cyan accents.
- **Dynamic Project Showcase:** Live GitHub API integration fetching recent repositories.
- **Interactive Experience:** Smooth scrolling, particle canvas background, parallax effects, and animated typing.
- **Fully Responsive:** Optimized for mobile, tablet, and desktop viewports.
- **Academic Highlights:** B.Tech CSE (Brainware University), Higher Secondary, and Madhyamik details.
- **Contact & Socials:** Direct connection links to GitHub, LinkedIn, and Email.

---

## 🛠️ Built With

- **HTML5** – Semantic markup and SEO-friendly structure
- **Vanilla CSS3** – Custom design tokens, glassmorphism, responsive grid & flexbox
- **JavaScript (ES6+)** – Interactive particles, typing effect, mobile navigation, and GitHub REST API integration
